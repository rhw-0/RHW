# Resolution Heavy Works Web App - V4.0 Preview

V4.0 remains an unreleased Draft PR. Production `main` stays on V3.6 until explicitly merged.

`OPERATIONS / ITEM CALCULATOR` is a recipe-first costing tool backed by Discovery's public game configuration. It supports recipe search, output quantity, IFF, material unit prices, build cost, cost per output, target profit margin, recommended sell price, revenue and profit. Material prices are saved locally in the browser and reused across recipes.
