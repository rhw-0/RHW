# Resolution Heavy Works Web App - V4.0 Preview

V4.0 remains an unreleased Draft PR. Production `main` stays on V3.6 until explicitly merged.

The V4 preview includes COMMAND, OPERATIONS and COMMS workspaces. `OPERATIONS / ITEM CALCULATOR` is a recipe-first costing tool backed by the public Discovery game configuration at `https://discoverygc.com/gameconfigpublic/`. Search a recipe, set output quantity and IFF, enter material unit prices, then RHW calculates material requirements, build cost, cost per output, target profit margin, recommended sell price, revenue and profit. Material prices are stored only in the browser and reused across recipes.
